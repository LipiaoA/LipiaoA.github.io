你好，我是 **Atlas**。

也是「一个不太喜欢吃的吃货」——名字有点随意，但写的内容很认真。

最初只是随手起的一个名字，但后来发现它恰好描述了自己：

对于很多事情，并不算天赋出众，也谈不上狂热执着，只是好奇，想知道它们为何会如此，无论是一本书、一段历史、一片陌生的土地，还是一颗处理器。

与其说喜欢「拥有答案」，不如说喜欢「寻找答案」

## 目前主要关注

- 计算机体系结构
- RISC-V
- 高性能处理器设计
- Linux 系统软件
- 工程实践

这个博客用于记录学习过程中的思考与实践。

从超标量处理器到操作系统，从代码到系统，从阅读到旅行。

持续学习，持续记录。
