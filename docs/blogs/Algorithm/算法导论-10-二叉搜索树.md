##### 1.二叉搜索树

一棵二叉搜索树是以以一棵二叉树来组织的，二叉树中每个节点就是一个对象元素。除了 $key ，val$ 数据外，还包含 $left，right$ 和 $p$ 指针，分别指向左子节点、右子节点和父节点。二叉搜索树中的关键字总是以满足二叉搜索树的性质的方式来存储：

> 设 $x$ 是二叉搜索树中的一个节点， $y$ 是 $x$ 的左子树中的一个节点，那么 $y.key \leq x.key$ 。如果 $y$ 是 $x$ 右子树中的一个节点，那么 $y.key \geq x.key$ 。

简单来讲，比 $x$ 关键字小的元素都在它左子树上，比 $x$ 关键字大的都在它右子树上。

```c
typedef struct Node {
    int val;
    struct Node *left;
    struct Node *right;
} Node;

void inorder(Node *root) {
    if (root == NULL)
        return;
    inorder(root->left);      // 1. 遍历左子树
    printf("%d ", root->val); // 2. 访问根节点
    inorder(root->right);     // 3. 遍历右子树
}
```



##### 2.操作

**遍历**

根据定义，可以知道的是，一棵二叉搜索树经过一次中序遍历之后可以得到有序的 $key$ 序列。遍历一棵有 $n$ 个节点的二叉搜索树需要耗费 $\Theta (n)$ 的时间，后续说明基于上述算法实现。

定理： 如果 $x$ 是一棵有 $n$ 个结点子树的根，那么递归实现中序遍历一次，需要 $\Theta(n)$ 的时间。

证明： $T(n)$ 表示遍历 $n$ 个结点执行时间，因此 $T(n) = \Omega (n)$ ，下一步说明 $T(n) = O(n)$ 。

对于一棵空树，算法需要一个常数时间，因此 $T(0) = c \; (c>0)$ 。

对 $n > 0$ ，假设算法作用在一个结点 $x$ 上，$x$ 结点左子树有 $k$ 个结点，右子树有 $n - k - 1$ 个结点，则算法执行时间有 $T(n) \leqslant T(k) + T(n-k-1) +d$ ，其中常数 $d > 0$ ，表达式指示算法执行时间上界，不过没包含递归调用花费时间。使用替换算法，通过证明 $T(n) \leqslant (c + d) n + c$，可以得到 $T(n) = O(n)$ 。

**查询**

查找**特定关键字**，算法实现比较简单，拿到一个结点与查找 $key$ 比较，相等返回，小于就往左子树查，大于往右子树查找，实现如下：

```c
Node* bst_search(Node *root, int key) {
    if (root == NULL || root->val == key)
        return root;

    if (key < root->val)
        return bst_search(root->left, key);
    else
        return bst_search(root->right, key);
}
```

查找**最大关键字和最小关键字**，对于最大关键字，只需要一直往右子树走即可，直到右子节点为空停止，最小关键字则相反，往左子树走。

查找某个结点的**前驱和后继**结点，对于给定的一棵二叉搜索树，有时需要查找给定关键字 $x$ 按照中序遍历的前驱和后继结点。一棵二叉搜索树结构允许我们可以不通过关键字的比较来找到其前驱或者后继结点，实现分两种情况处理即可（查后继结点）：

1.  $x$ 右子树不为空，查其右子树中最小的结点返回即可。
2. 右子树为空，则从当前结点往上查找，直到查找到第一个 $x$ 非其右子树的结点的父节点 $y$ 即可。

对于上述查找实现，其运行时间都为 $O (h)$ ，h为树高度。



**插入**

插入实现比较简单，从根节点开始向下比较，直到找到一个找到一个空的位置，将其插入即可，代码如下：

```c
Node* bst_insert(Node *root, int val) {
    if (root == NULL) {
        Node *n = malloc(sizeof(Node));
        n->val = val;
        n->left = n->right = NULL;
        return n;
    }

    if (val < root->val)
        root->left = bst_insert(root->left, val);
    else if (val > root->val)
        root->right = bst_insert(root->right, val);
    return root;
}

```



**删除**

二叉搜索树删除分三种情况讨论，只有一种比较棘手，对于删除 $z$ 结点：

1. 如果 $z$ 没有子节点，那么直接删除即可，其父节点对应位置置空。
2. 如果 $z$ 只有一个子节点，将该子节点提升到树种 $z$ 的位置上，修改父节点，用 $z$ 的子节点来替换 $z$ 。
3. 如果 $z$ 有两个子节点，那么查找 $z$ 的后继 $y$ ，并让 $y$ 占据树中 $z$ 的位置，递归删除 $y$ 节点即可。

```c
Node* bst_delete_successor(Node* root, int key) {
    if (!root) return NULL;

    if (key < root->val)
        root->left = bst_delete_successor(root->left, key);
    else if (key > root->val)
        root->right = bst_delete_successor(root->right, key);
    else {
        if (!root->left && !root->right) {
            free(root);
            return NULL;
        }

        if (!root->left) {
            Node *r = root->right;
            free(root);
            return r;
        }
        if (!root->right) {
            Node *l = root->left;
            free(root);
            return l;
        }

        Node *succ = bst_min(root->right);  // 右子树最小（中序后继）
        root->val = succ->val;
        root->right = bst_delete_successor(root->right, succ->val);
    }
    return root;
}

```

代码实现完美诠释了算法描述的过程，酌情欣赏，执行删除结点算法时间也是 $O(h)$，其中 $h$ 为树高度。



##### 3.随机构建二叉搜索树

​	二叉搜索树的查询、插入、删除操作都可以在 $O(h)$ 时间内完成，$h$ 为树高度。然而，随着元素插入和删除，二叉树的高度是变化的。看个简单例子，如果 $n$ 个关键字的按照严格的递增次序插入，那么这棵树是高度为 $n - 1$ 的一条链。虽然如此，我们可以证明其平均情况下的性能接近最好情况下的性能，而不是最坏情况。

​	对于一棵通过有插入有删除而生成的树时，这种情形不好分析，我们考虑这棵树是由插入操作生成的情形。定义 $n$ 个关键字的一棵随机构建二叉树为按随机次序插入这些关键字到一棵初始为空的树中而生成的树，这里输入关键字的 $n!$ 个排列都是等可能地出现。下面证明它的期望高度为 $O(\lg n)$ 。

定义一些随机变量，$X_n$ 表示一棵由 $n$ 个关键字的随机构建二叉树的高度，并定义**指数高度** $Y_n = 2^{X_n}$ 。构造一棵 $n$ 个关键字的二叉搜索树时，选择一个关键字作为树根，并设 $\bf R_n$ 为一个随机变量，表示这个关键字在 $n$ 个关键字集合中的秩，即 $R_n$ 表示这些关键字排好序后这个关键字应占据的位置，$R_n$ 对于集合 $\{1，2，... ，n\}$ 中的任何元素都是等可能的。有：
$$
Y_n = 2 \;\cdot \;max(Y_{i-1},Y_{n-i})
$$
作为基础情况，设 $Y_1 =  1$ ，为方便起见定义 $Y_0 = 0$ 。定义指示器随机变量 $Z_{n , 1}，Z_{n , 2}，\cdots ，Z_{n , n}$ ，其中 $Z_{n,i} = I\{R_n = i\}$ ，有：
$$
E[Z_{n,i}] = \frac{1}{n}
$$
其中 $i = 1,2,\cdots n$ 。由于 $Z_{n,i}$ 恰有一个值为1，其余值为0，因此有：
$$
Y_n = \sum_{i=1}^{n}Z_{n,i}(2\cdot max(Y_{i-1},Y_{n-i}))
$$
下面证明 $E[Y_n]$ 是 $n$ 的一个多项式，由此最终得到 $E[X_n] = O(\lg n)$ 。$Z_{n,i}$ 独立于 $Y_{i-1}$ 和 $Y_{n-i}$ 的值（当选定 $R_n = i$ 时，其两个子树的结构跟选哪个 $i$ 没关系）。所以有：
$$
\begin{array}{ll}
E[Y_n] & = & \displaystyle \frac{2}{n} \sum\limits_{i=1}^{n} {E[max(Y_{i-1}, Y_{n-i})]} \\
 & \leqslant & \displaystyle \frac{2}{n} \sum\limits_{i=1}^{n} {(E[Y_{i-1}] + E[Y_{n-i}])}
\end{array}
$$
中间过程比较简单，省略记录，进一步有：
$$
E[Y_n] \leqslant \frac{4}{n} \sum_{i=0}^{n-1}{E[Y_i]}
$$
用替换算法证明对所有的正整数 $n$ ，上式解为：
$$
E[Y_n] \leqslant \frac{1}{4} \binom{n+3}{3}
$$
对于基础情况，注意到两个界 $0 = Y_0 = E[Y_0] \leqslant (1/4) \binom{3}{3} = 1/4$ 和 $1 = Y_1 = E[Y_1] \leqslant (1/4) \binom{1+3}{3} = 1$ 成立。对于归纳情况，有：
$$
E[Y_n] \leqslant \frac{4}{n} \sum_{i=0}^{n-1}{E[Y_i]} \leqslant \frac{4}{n} \sum_{i=0}^{n-1}{\frac{1}{4}\binom{i+3}{3}} \\
= \frac{1}{n} \binom{n+3}{4} = \frac{1}{4}\binom{n+3}{3}
$$
继续：
$$
2^{E[X_n]} \leqslant E[2^{X_n}] = E[Y_n]
$$
由此：
$$
E[X_n] = O(\lg n)
$$
