#### 动态规划

###### 一、0-1 背包问题：

​		有n个重量和价值分别为wi，vi的物品。从这些物品中挑选出部分物品，使得其总重量不超过W，求所有挑选方案中价值总和的最大值。

###### 解决方案：

​	1、针对每个物品是否放入进行搜索。

```c++
//递归实现
int n,W;//n为物品个数 W为背包总重量
int w[MAX_N],v[MAX_N];//分别对应重量与价值
int rec(int i, int rev)//从第i个物品开始挑选，并返回总重不小于rev的物品最大价值
{
	int res;
	if(i == n)//已无剩余物品
		res = 0;
	else if(w[i] > rev)//无法挑选该物品。
		res = rec(i+1, rev);
	else //尝试计算不选择第i个物品和选择第i个物品的情况，取其最大值
		res = max(rec(i+1, rev),rec(i+1, rev - w[i]) + v[i]);
	return res;//返回最大价值
}
```

​	先看一种情况：

```c++
int n=4, W = 5;
int w[4]={2, 1, 3, 2};
int v[4]={3, 2, 4, 2};
```

​	由图以递归方式求解，物品从第0个开始选取，判断第0个物品时，背包剩余容量为5，分选取和不选取两种情况，以此递推。由图可知，在整个计算过程中，当判断到第3个物品剩余容量为2的情况重复计算一次，因此，是否可以将在整个计算过程中已经计算出的值保存起来，避免重复计算？答案是可以的。

代码如下：

```c++
//递归实现 在之前基础上加入dp数组保存中间结果
int n,W;//物品个数，总重量
int w[MAX_N],v[MAX_N];//分别对应重量与价值
int dp[MAX_N + 1][MAX_M + 1]; // dp[i][j]表示挑选第i个物品，剩余重量为j时的最大价值。

int rec(int i, int j)//从第i个物品开始挑选，并返回总重不小于j的物品最大价值
{
    int res;
	if(dp[i][j] >= 0)//表示该第i个物品，剩余容量j的情况已经计算过，直接返回。
		return dp[i][j];

    if(i == n)//已无剩余物品
        res = 0;
    else if(w[i] > j)//无法挑选该物品。
        res = rec(i+1, j);
    else
        res = max(rec(i+1, j),rec(i+1, j - w[i]) + v[i]);
    dp[i][j] = res;//将该次调用计算结果保存
    return res;
}
```

说明：我们定义了二维数组dp（在使用之前应该将其所有值初始化为-1，表示未计算过）在递归过程中用来存储一次计算的结果。分析上述过程中dp数组，dp存储了 挑选到第i个物品且剩余重量 j 的最大价值。在有物品可选且该物品能放入背包的情况下（即上述代码最后else处理的情况），我们分别计算不选取第i个物品与选取第i个物品情况，并取其中的最大值，即分别对应于`dp[i+1][j]`（不选取第i个物品）和`dp[i+1][j - w[i]] +v[i]` (选取第i个物品);则可得以下递推式：

```c
//递推式1
dp[n][j] =0;
dp[i][j]分两种情况：
当j < w[i]时, dp[i][j] = dp[i+1][j];
其他情况下 dp[i][j] = max(dp[i+1][j], dp[i+1][j-w[i]] + v[i]);
```

因此我们可通过以下代码实现：

```c
//动态规划实现
int dp[MAX_N + 1][MAX_W + 1];
//w[] v[] 表示重量与价值对
void slove()
{
	for(int i = n -1; i >= 0; i--)
	{
		for(int j = 0; j <= W; j++ )
		{
			if(j < w[i])
			{
				dp[i][j] = dp[i+1][j];
			}
			else
			{
				dp[i][j] = max(dp[i + 1][j], dp[i+1][j - w[i]] + v[i]);
			}
		}
	}
	printf("max value:%d", dp[0][W]);
	return;
}
```

​		现在讨论下递归调用的过程，每次函数调用最坏情况下其包含两个分支，因此其时间复杂度为O(2^n)。以上通过递推公式实现的代码其复杂度降到了O(nW)，这一类将其计算出的结果保存，后期计算在之前的基础上一步一步得出结果的问题解决方法为动态规划。

​		在该问题的递归实现中，判断一个物品是否放入背包是从第0个物品开始，但由于递归性质，其得到实际结果返回是在递归调用栈底部一步步向上返回得出结果（这一点可参考上图中理解，其调用过程大致和对树的一次后序遍历），由此可知其对dp数组的赋值则是从第n个物品开始直到第0个物品完成。

​		对上述递推式分析，其计算过程有第n个物品开始直到第0个物品，由此可换下思路从第0个物品开始到第n个，则可得一下递推式：

```c
//递推式2
dp[0][j] =0;
dp[i+1][j]分两种情况：
当j < w[i]时, dp[i+1][j] = dp[i][j]; //当剩余容量小于当前物品重量时无法放入
j >= w[i]时, dp[i+1][j] = max(dp[i][j], dp[i][j-w[i]] + v[i]);
```

综述：

​		动态规划问题，关键在于找到递推式，即将待解决的问题分解为多个小问题，再找到分解后问题之间的联系，再一步步求解。在找到递推式之前，先得定义好数组及实际意义，即针对的各个小问题，这也是比较麻烦的一步。
