#### 0.动态规划

动态规划（dynamic programming）与分治算法类似，都是通过组合子问题的解来求解原问题的解。分治的方法将问题划分为不相交的子问题，递归求解子问题，再将它们组合起来，求出原问题的解。与之不同的是，动态规划应用于子子问题出现重叠的情况，即不同的子问题有共同的子子问题。在这种情况下，分治方法会做很多不必要的重复求解工作，而动态规划算法对每个子子问题只做一次求解，将解保存在一个表格中，从而避免不必要的重复计算工作。

动态规划通常应用于求解最优化问题。这类问题通常会存在多个可行解，每个解对应一个值，而我们需要找具有最优值得解。通常可按照下面的步骤来设计一个动态规划算法：

1. 刻画一个最优解的结构特征
2. 递归定义最优解的值
3. 计算最优解的值，通常采用自底向上的方法
4. 利用计算出的信息构造一个最优解

前面3步是动态规划求解问题基础，如果我们只需要一个最优解值，可以不用第4步。接下来我们先实践两个例子，进一步讨论动态规划应用问题应该具备的两个关键特征，最后以两个问题的解决做收尾。

#### 1.钢条切割

##### 1.1.问题描述

给定一段长度为 $$n$$ 英寸的钢条和一个价格表 $$p_i(i = 1，2，\dots ，n)$$ ，求钢条的切割方案，能够得到最大销售收益 $$r_n$$ （当然，如果 $$p_n$$ 足够大，那也可以选择不做切割，此时 $$ r_n =  p_n $$）。

对于一个长度为 $$ n $$ 的钢条，总共有 $$ n-1 $$ 可供切割点，而对于每一个切割点我们可以选择切割或者不切割，因此，一段长度为 $$ n $$ 的钢条，总共的切割方案有 $$ 2^{n-1} $$ 种。

假定一个最优解将钢条切割为 $$k(1\leq k \leq n)$$ 段，那么最优切割方案
$$
n = i_1 + i_2 + ... + i_k
$$
将钢条分别切割长度为 $$ i_1,i_2,...,i_k $$ 的小段，此时得到最大收益为：
$$
r_n = p_{i_1} + p_{i_2} + ... + p_{i_k}
$$
当然，更一般的，对于 $$r_n(n\geq 1) $$，我们可以用更短的钢条切割收益来进行描述：
$$
r_n = max(p_n, r_1 + r_{n-1}, r_2 + r_{n-2}, ... ,r_{n-1} + r_1 )
$$

简单的拆解写，上述计算方式对每个 $$i = 1，2，\dots ，n - 1 $$ ，首先将钢条切割为 $$i $$ 和 $$n-i$$ 长度的两段，接着求解这两段的最优切割收益 $$ r_i $$ 和 $$r_{n-i} $$ 之和，因为无法预知，需要将这 $$n-1$$ 种方案都计算一遍，选出最大的。

##### 1.2.朴素递归

注意到，为了求解规模为 $$n$$ 的问题，我们先求解形式完全一样，但是规模更小的子问题。即完成首次切割后，我们将两段钢条看做两个独立的钢条切割问题实例。通过组合两个相关子问题的最优解，并在所有可能的两段切割方案中选取组合收益最大者，够成原问题的最优解。问题的最优解由相关子问题的最优解组合而成，而这些子问题可以独立求解的结构，称为**最优子结构**。

除了上述方案外，上述问题还有另一个简化方案，我们将钢条一端切下长度为 $$i(1\leq i \leq n)$$ 的一段，只对剩下的 $$n-i$$ 部分继续进行切割。因此我们将问题转换为左边开始一段以及剩余部分继续分解的结果，表达如下：
$$
r_n = max(p_i+r_{n-i})
$$
在这个公式中，最优解只包含一个相关子问题的解而不是两个，实现代码如下：

```c
int cut_rod(int p[], int n) {
	int q = INT_MIN;
    if (n ==0) {
        return 0
    }
    for (int i = 1; i <= n; ++i) {
        q = max(q, p[i] + cut_rod(p, n-i));
    }
    return q;
}
```

图中显示了 $$n = 4 $$ 时上述函数的调用处理过程，能看到其中值为 $$ 0，1，2 $$ 的时候被多次进行计算了。当计算的 $$n$$ 增大时，这个计算工作量将爆炸性增长。



为了分析上述函数调用时间，令 $$T(n)$$ 表示第二个参数值为 $$n$$ 时函数的调用次数，此值等于递归调用树中根为 $$n$$ 的子树中的结点总数，$$T(0) = 1 $$ 且
$$
T(n) = 1 + \sum_{j=0}^{n-1}{T(j)}
$$
第一项表示第一次调用，后面为计算子问题的调用次数总和，结果为：
$$
T(n) = 2^n
$$
回头看，其指数运行时间其实也是正常的，上述计算过程对于长度为 $$n$$ 的钢条，它考虑了其 $$2^{n-1}$$ 种可能的方案，算是暴力求解了。

下面我们使用动态规划方法求解最优钢条切割问题

上面的朴素递归调用算法之所以效率很低，是因为它反复求相同的子问题。因此，动态规划方法仔细的安排子问题的求解顺序，对每个子问题只求解一次，并将结果保存下来。后续如果需要使用此问题的解只需要做查找即可，不需要重复计算。因此，动态规划方法是付出额外的内存空间来节省计算时间，典型的时空权衡例子。时间上得节省是巨大的：可能将一个指数时间的解转化为一个多项式时间的解。

##### 1.3.动态规划实现

第一种是带备忘的自顶向下法。该方法仍按照自然的递归形式编写过程，但过程会保存每个子问题的解（数组或者散列表），当需要求解一个子问题时，先对该表进行查找。

第二种是自底向上的方法。这种方式需要恰当的定义子问题的“规模”概念，使得任何子问题的求解都只依赖于更小规模的子问题的解。因而，我们可以按照子问题的规模排序，从最小的子问题开始求解，使得在求解某一个问题时，保证其依赖的更小规模的子问题已经求解完毕，结果已经保存，这样就能很好的保证每个问题只求解一次。

分别给出两个方案对应的代码实现：

```c++
static vector<int> r(n, -1);
int mem_cut_rod(vector<int> p, int n) {
    int q = 0;
    if (r[n] > 0) return r[n];
    if (n == 0) q = 0;
    else {
        q = -1;
        for (int i = 1; i <= n; ++i) {
            q = max(q, p[i] + mem_cut_rod(p, n - i));
        }
    }
    r[n] = q;
    return q;
}
```

自底向上的方案实现：

```c++
int button_up_cut_rod(vector<int> p, int n) {
    vector<int> r(n, -1);
    r[0] = 0;
    for (int i = 1; i <= n; ++i) {
        int q = -1;
        for (int j = 1; j <= i; ++j) {
            q = max(q, p[i] + r[i - j]);
        }
        r[i] = q;
    }
    return r[n];
}
```

从实现中能看出来，内层循环是计算长度为 $$i$$ 的最优解并保存在 `r[i]` 中，而外层循环是保证计算按照从小规模的子问题向更大规模子问题依次计算的过程，直到规模为 $$n$$ 的问题被求解才退出循环。

自底向上和自顶向下的计算方法有相同的渐进运行时间，仅有的差异是在某些特殊情况下，自顶向下的方法并没有真正递归的考察所有可能的子问题。由于没有频繁的递归函数调用开销，自底向上的方法的时间复杂度函数通常具有更小的系数。上述两种方法实现上不难分析出，其渐近运行时间同为 $$\Theta(n^2) $$ 。

显示了 $$n = 4 $$ 情况下钢条切割问题的子问题图。是一个有向图，每个顶点唯一的对应一个子问题。若求子问题 $$x$$ 的最优解时需要用到子问题 $$y$$ 的最优解，那么在子问题图中就会有一条从子问题 $$x$$ 顶点指向子问题顶点 $$y$$ 的一条有向边。

自底向上的动态规划方法处理子问题图中顶点的顺序为：对于一个给定的子问题 $$x$$ ，在求解它之前求解邻接至它的子问题 $$y$$，是按照图中的一个逆拓扑序来进行计算的过程。

##### 1.5.重构解

上述给出的钢条切割的动态规划算法返回了最优解的收益值，但并未返回解本身（即如何切割）。我们可以扩展下，不仅对每个解保存最优值同时也保存下对应的切割方案，利用这些信息我们可以拿到最优解的切割方案。

```c++
int ext_button_up_rod(vector<int> p, int n) {
	vector<int> r(n+1, -1), s(n+1);
    r[0] = 0;
    for (int i = 1; i <= n; ++i) {
        int q = -1;
        for (int j = 1; j <= i; ++j) {
            if (q < p[j] + r[i - j]) {
                q = p[j] + r[i - j];
                s[i] = j;
            }
        }
        r[i] = q;
    }
    while (n > 0) {
        cout << s[n] << " ";
        n -= s[n];
    }
    return r[n];
}
```

在上述代码中，与之前实现区别是补充了数组 `s` 用于保存求解到最优解时第一段钢条的长度值，后续即可根据该数组得到最优切割方案。

#### 2.矩阵乘法

##### 2.1.背景信息

给定一个 $$n$$ 个矩阵的序列 $$\langle A_1,A_2,\dots,A_n \rangle $$ ，我们希望计算它们的乘积
$$
A_1 A_2 \cdots A_n
$$
为了计算上述表达式，我们可以用括号明确计算次序，然后利用标准的矩阵乘法进行计算。因矩阵乘法满足结合律，因此任何加括号的方案都会得到相同的结果。对矩阵链加括号的方式会对乘积运算的代价产生巨大的影响，不同的计算次序会导致其总的标量乘法次数不同。矩阵链完全括号化是指：它是一个单一矩阵，或者是两个已完全括号化的矩阵链的乘积且已外加括号。

以三个矩阵乘法为例， $$\langle A_1,A_2,A_3 \rangle $$ 规模分别为 10 X 100、100 X 5、5 X 50，按 $$((A_1A_2)A_3)$$ 顺序计算，两次矩阵乘法计算代价之和为 $$ 10 \cdot 100 \cdot 5 + 10 \cdot 100 \cdot 50 = 7500$$ 次标量乘法；按照 $$(A_1(A_2A_3))$$ 顺序计算，总代价为 $$ 100 \cdot 5 \cdot 50 + 10 \cdot 100 \cdot 50 = 75000 $$ 次标量乘法。因此按照第一种顺序计算将比第二种快10倍。

问题描述：给定 $$n$$ 个矩阵的链 $$\langle A_1,A_2,\dots,A_n \rangle $$ ，矩阵 $$A_i$$ 的规模为 $$ p_{i-1} X p_i (1 \leq i \leq n) $$ ，求完全括号化方案，使得计算乘积 $$ A_1A_2\cdots A_n$$ 所需的标量乘法次数最少。 



##### 2.2.计算括号化方案数量

对一个 $$n$$ 个矩阵的链，令 $$P(n) $$ 表示可供选择的括号化方案数量，容易知道 $$P(1) = 1$$ ，当 $$n > 2$$ 时，完全括号化的矩阵乘积可以描述为两个完全括号化的部分积相乘的形式，而两个部分积的划分点在第 $$k$$ 个矩阵和第 $$k + 1 $$ 个矩阵之间， $$ k$$ 为 $$ 1, 2, \dots ,n-1 $$ 中的任意一值，可以得到：
$$
P(n) = \left\{\begin{array}{ll}
1 & 如果 n = 1 \\
\sum\limits_{k=1}^{n-1}{P(k)P(n-k)} & 如果 n \geq 2
\end{array} \right.
$$
通过计算可以得到 $$P(n) = \Omega(2^n) $$ ，因此，括号化方案的数量与 $$n$$ 呈指数关系，通过暴力搜索来寻找不太理想。

##### 2.3.动态规划方法

按照文章开头给出的步骤进行：

1. 刻画一个最优解的结构特征
2. 递归定义最优解的值
3. 计算最优解的值，通常采用自底向上的方法
4. 利用计算出的信息构造一个最优解



**步骤1：刻画最优解结构特征**

对于求解矩阵链乘法问题，我们用符号 $$A_{i..j} $$ 表示 $$A_iA_{i+1}\cdots A_j $$ 乘积的结果矩阵。可以看到，为了对 $$A_iA_{i+1}\cdots A_j $$ 进行括号化，我们必须在某个矩阵 $$A_k$$ 和 $$A_{k+1} $$ 之间将矩阵链分开$$（ k \; 为 i \leqslant k < j \;间的一个整数）$$。也就是说，对于某个整数 $$k$$ 我们先计算 $$A_{i..k} $$  和 $$A_{k+1..j} $$ ，再计算 它们的乘积，最终得到 $$A_{i..j} $$ ，此方案的代价等于计算  $$A_{i..k} $$  和 $$A_{k+1..j} $$ 的代价加上这两者相乘的代价。

这里假定  $$A_iA_{i+1}\cdots A_j $$ 最优化括号方案的分割点在 $$A_k$$ 和 $$A_{k+1} $$ 之间，那么对“前缀”子链进行括号化时，我们应该直接采用独立求解它时所得的最优方案。这样做的原因是什么？如果我们不采用独立求解  $$A_iA_{i+1}\cdots A_k $$ 时所得到的最优括号化方案对其进行括号化，那么可以将此最优解代入 $$A_iA_{i+1}\cdots A_j $$ 的最优解中，代替原来 $$A_iA_{i+1}\cdots A_k $$ 的括号化方案，显然这样得到的解比原来  $$A_iA_{i+1}\cdots A_j $$ 的“最优解”代价更低，因此产生矛盾。对子链 $$A_{k+1}\cdots A_j $$ 我们有相同的结论。

现在展示如何利用最优子结构性质从子问题的最优解构造原问题的最优解。我们看到一个非平凡的矩阵链乘法问题实例都需要划分链，而任何最优解都是由子问题的最优解实例构成的。因此，为了构造一个矩阵链乘法问题实例的最优解，我们将问题划分为两个子问题，求解出两个子问题的最优解，最后组合起来形成原问题的最优解。这需要注意的是在确定分割点是，需要确保所有可能的位置已经考察过一次。

*初始在看的时候，为何可以直接将“前缀”链代进去？这个前缀子链是可以再被划分的，后面仔细想了下，已经确定了前提条件是最优的划分点，因此这个前缀链就是一个整体（相对于另一部分而言），因此可以直接代进去计算。*



**步骤2：一个递归求解方案**

我们将对所有 $$1 \leqslant i \leqslant j \leqslant n $$ 确定 $$A_iA_{i+1}\cdots A_j $$ 的最小括号化方案作为子问题。令 `m[i, j]` 表示计算矩阵 $$A_{i..j} $$ 所需标量乘法次数的最小值。那么原问题的最优解 ---- 计算 $$ A_{1..n} $$ 所需的最低代价就是 $$m[1，n] $$ 。对于 $$i = j $$ 的情况，计算代价为 0，对于 $$ i < j$$ 的情况，我们使用上一个步骤中得到最优子结构来计算 $$m[i, j] $$ 。假定 $$A_iA_{i+1}\cdots A_j $$ 的最优括号化方案的分割点在矩阵 $$A_k$$ 和 $$ A_{k+1} $$ 之间，其中 $$ i \leqslant k < j $$ 。那么，$$ m[i, j] $$ 就等于计算 $$A_{i..k} $$ 和 $$ A_{k+1..j} $$ 的代价，加上两者相乘的代价最小值。由于矩阵$$ A_i$$ 的大小为 $$p_{i-1} \times p_i $$ ，可以知道 $$A_{i..k} $$ 与 $$A_{k+1..j} $$ 相乘的代价为 $$ p_{i-1} p_k p_j $$ 次标量运算。因此可以得到：
$$
m[i, j] = m[i, k] + m[k+1, j] + p_{i-1} \cdot p_k \cdot p_j
$$
上述递归式假定最优分割点是已知的，但实际上不知道，但我们只需要迭代 $$j - i $$ 种可能的取值即可，最优分割点必在其中。可以得到：
$$
m[i, j] = \left\{ \begin{array}{ll}
0 & 如果 \; i = j \\
\min\limits_{i\leqslant k < j}\{ m[i, k] + m[k+1, j] + p_{i-1}p_k p_j\} & 如果\;i<j
\end{array} \right.
$$
$$m[i, j] $$ 的值给出了子问题的最优解的代价，但它并未提供足够的信息来构造最优解。为此，可以使用另一个数组 $$ s[i, j] $$ 来保存 $$A_iA_{i+1}\cdots A_j $$ 最优化括号方案的分割点位置 $$k$$ ，即使 $$ m[i, j] = m[i, k] + m[k+1, j] + p_{i-1} \cdot p_k \cdot p_j $$ 成立的 $$k$$ 值。



**步骤3：计算最优代价**

从上述递归方案可以看出，我们需要求解的总的子问题数目相对较少的，共有 $$ \binom{n}{2} + n = \Theta(n^2) $$ 个，在这我们使用自底向上的方法代替上一步中递归公式来进行计算最优代价，为了实现该方式，我们需要确定计算 $$m[i, j] $$ 时需要依赖哪些其它表项，这个通过之前子任务的划分情况，可以知道的是其依赖于比它自身链更短的链表项，因此可以确定我们算法需要按照长度递增的顺序求解矩阵链括号化问题，按照对应的顺序填写表 $$m$$ ，实现如下：

```c++
void matrix_chain_order(vector<int> p) {
    int n = p.size() - 1;
    vector<vector<int>> m(n+1, 0), s(n+1);
    for (int l = 2; i <= n; ++l) { 				// 该层循环限定矩阵链长度，按照长度递增方式最优括号化
        for (int i = 1; i <= n - l + 1) {		// 确保l长度下，迭代每个子链
            int j = l + i - 1;					// 子链最后元素位置计算
            m[i, j] = MAX_INT;
            for (int k = i; k <= j - 1; ++k) {  // 遍历每个可能的划分点，循环体选取并记录其中最优的划分点
                int q = m[i, k] + m[k + 1, j] + p[i - 1] * p[k] * p[j];
                if (q < m[i, j]) {
                    m[j, j] = q;
                    s[j, j] = k;
                }
            }
        }
    }
    // 此处 m s 即为我们需要的结果矩阵
    return;
}
```

代码中已做说明，最后我们只需要打印出 $$ m[1, n] $$ 的结果，并回溯最优划分点就可以拿到划分方案。



**步骤4：构造一个最优解**

上一步虽然给出了矩阵链乘法所需最小标量乘法运算次数，但并未指出如何进行这种最优代价的矩阵链乘法计算。代码中的数组 `s` 记录了构造最优解所需要的信息。每个表项 `s[i, j]` 记录了一个 k 值，指出 $$A_iA_{i+1}\cdots A_j $$ 的最优括号化方案的分割点应该在 $$A_k$$ 和 $$ A_{k+1} $$ 之间。因此，可以得到下面的代码：

```c++
void print_optimal_parens(vector<vector<int>> s, int i, int j) {
	if (i == j) printf("A%d", i);
    else {
        printf("(");
        print_optimal_parens(s, i, s[i, j]);
        print_optimal_parens(s, s[i, j] + 1, j);
    	printf(")");
    }
}
```

#### 3.动态规划原理

前面已经用动态规划的方法解决了两个问题，本节关注下在工程应用中，何种情况下需要寻求动态规划方法求解问题，即适合应用动态规划方法求解的最优化问题应该具备的两个要素：最优子结构和问题重叠。将再次讨论备忘方法，更深入的讨论在自顶向下方法中如何借助备忘机制充分利用子问题重叠特性。

##### 3.1.最优子结构

使用动态规划求解最优化问题的第一步就是刻画最优子结构，如前文所述，如果一个问题的最优解包含其子问题的最优解，我们称此问题具有最优子结构性质。因此确认问题是否有最优子结构性质可以成为判断能否使用动态规划求解的线索（可能适用于贪心算法）。

前面给出的两个问题也都具有最优子结构的性质。对于钢条切割问题，长度为 $$n$$ 的钢条的最优解是由第一次切割后得到的两段钢条的最优切割方案组成的。对于矩阵链乘法问题，$$A_iA_{i+1}\cdots A_j $$ 的最优括号化方案首先再 $$A_k$$ 和 $$A_{k+1} $$ 之间进行划分，然后继续对 $$A_iA_{i+1}\cdots A_k $$ 和  $$A_{k+1}A_{k+2}\cdots A_j $$ 继续进行最优括号化。其发掘最优子结构性质过程中，遵循了如下通用模式：

1. 证明问题的最优解的第一个组成部分是做出一个选择，比如选择钢条切割位置，选择矩阵链划分位置等。做出选择后会产生多个待解决的子问题。
2. 对一个给定的问题，在可能的第1步选择中，假定已经知道哪种选择才会得到最优解（暂时不关心这种选择具体如何得到，只是已经知道这个选择了）。
3. 给定可获得的最优解之后，你确定这次选择会产生哪些子问题，以及如何最好的刻画子问题空间。
4. 利用反证法技术证明：作为构成原问题最优解的组成部分，每个子问题的解就是它自身的最优解。反证法：假定子问题的解不是其自身的最优解，那么将这个子问题的最优解代入到原问题中，从而得到原问题的一个更优解，这与最初的解是原问题的最优解的前提假设矛盾。



刻画子问题空间：保持子问题空间尽量简单，只在必要的时候才扩展它。比如在求解钢条切割问题时，子问题空间中包含的问题为：对每个 $$i$$ 值，长度为 $$ i $$ 的钢条的最优切割问题。与之相似，假定我们试图限制矩阵链  $$A_1A_{2}\cdots A_j $$ 乘法问题的子问题空间。如前所述，最优括号化方案必定在某个位置 $$k(1 \leqslant k < j)$$ 处 。除非我们能保证 $$k$$ 一直等于 $$j-1$$ ，否则我们会发现两个形如  $$A_1A_2\cdots A_k $$ 和  $$A_{k+1}A_{k+2}\cdots A_j $$ 的子问题，而后者的形式与 $$A_1A_{2}\cdots A_j $$ 是不同的。因此，对于矩阵链乘法问题，我们必须允许子问题在“两端”都可以变化，即允许子问题 $$A_iA_{i+1}\cdots A_j $$ 中的 $$i ，j$$ 都可变。



对不同的问题领域，最优子结构的不同体现在两个方面：一个是原问题的最优解中涉及多少个子问题，以及再确定最优解使用了哪些子问题时，我们需要考察多少中选择。在钢条切割问题中，长度为 $$n$$ 的钢条的最优切割方案只用了一个子问题，但我们必须要考察 $$i$$ 的 $$n$$ 种不同的取值，来确定哪一个会产生最优解。$$A_iA_{i+1} \cdots A_j $$ 的矩阵链乘法问题中，最优解使用了两个子问题，我们需要考察 $$ j - i $$ 种情况来确定哪一个是最优解。对于给定的矩阵链划分位置 $$A_k$$ ，我们需要求解 $$A_iA_{i+1}\cdots A_k $$ 和 $$A_{k+1}A_{k+2}\cdots A_j $$ 两个子问题的最优括号化方案，而且两个子问题都要求解最优括号化方案。一旦我们确认了子问题的最优解，我们就可以从 $$j-i $$ 个候选的 $$k$$ 中选出最优者。

我们可以利用子问题的总数和每个子问题需要考察多少种选择这两个因素来简单分析下动态规划算法的运行时间。对于钢条切割问题，共有 $$\Theta(n) $$ 个子问题，对于每个子问题我们最多需要考察 $$n$$ 种选择，因此，其运行时间为 $$O(n^2) $$。矩阵链乘法问题共有 $$\Theta(n^2) $$ 个子问题，对于每一个子问题，最多需要考察 $$n-1$$ 种选择，因此运行时间为 $$O(n^3) $$ 。在动态规划方法中，我们通常自底向上的使用最优子结构，也就是说先得到子问题的最优解，然后求原问题的最优解。在求解原问题过程中，我们需要做在涉及的子问题中做出选择，因此，原问题代价实际上等于求解子问题最优解的代价加上因此次选择所产生的直接代价。



**一些微妙之处**

在尝试使用动态规划时要小心，需要注意问题是否具有最优子结构性质。看下面两个问题，其中都给定一个有向图 $$ G = (V, E) $$ 和两个顶点 $$u，v \in V$$ 。

1. 无权最短路径：找到一条从 $$u$$ 到 $$v$$ 的边数最少的路径。这条路径必然是简单路径，因为如果存在环，那么将环去掉必然会减少边的数量。
2. 无权最长路径：找到一条从 $$u$$ 到 $$v$$ 的边数最多的路径。此处需要加上简单路径的要求，因为我们可以沿着环一直走，得到任意路径长度。

先证明无权最短路径长度具有最优子结构性质。假定 $$u \neq v$$ ，则问题是非平凡的。这样从 $$u$$ 到 $$v$$ 的路径 $$p$$ 都必须包含一个中间顶点 $$w$$（当然 $$w$$ 可能是 $$u$$ 或者 $$v$$ ），因此我们可以将路径 $$p$$ 分解为从 $$u$$ 到 $$w$$ 的路径 $$p_1$$ 和 从 $$w$$ 到 $$v$$ 的路径 $$p_2$$ 。显然，$$p$$ 的边数等于 $$p_1$$ 的边数加上 $$p_2$$ 的边数。于是我们断言：如果 $$p$$ 是从 $$u$$ 到 $$v$$ 的最优（最短）路径，那么 $$p_1$$ 必然是从 $$u$$ 到 $$w$$ 的最短路径。这个很容易用反证法证明，对 $$p_2$$ 也是一样。因此，我们可以通过遍历所有得中间节点 $$w$$ 来求 $$u$$ 到 $$v$$ 的最短路径，对每个中间顶点，求解 $$u$$ 到 $$w$$ 和 $$w$$ 到 $$v$$ 的最短路径，然后选择两条路径之和最短的顶点 $$w$$ 。

看起来无权最长简单路径问题也具有最优子结构性质，如果按照上述方法拆分路径 $$p_1，p_2$$ 之后这两者不是从 $$u$$ 到 $$w$$ 和从 $$w$$ 到 $$v$$ 的最长简单路径吗？答案是否定的。

![ScreenShot_2026-01-13_161939_236](D:/华为家庭存储/01-workspace/2-Docs/00-LeaRecord/ScreenShot_2026-01-13_161939_236.png)

上图给了个例子，考虑路径 $$q \rightarrow r \rightarrow t $$ ，它是从 $$q$$ 到 $$t$$ 的最长简单路径。但实际上在这条路径中，$$q \rightarrow r $$ 并非是从 $$q$$ 到 $$r$$ 的最长简单路径。因此可以说明，不仅缺乏最优子结构的性质，并且由子问题的解组合出的甚至都不是原问题的 "合法" 解。的确，该问题看起来不像有任何形式的最优子结构。对此问题尚未找到有效的动态规划算法。实际上，该问题是 $$NP$$ 完全的，这意味着不太可能找到能在多项式时间内解决的算法。

上述最长简单路径的问题与最短简单路径问题的区别在于，最长简单路径划分的两个子问题是相关的，而最短简单路径的两个子问题是不相关的（一个问题的解不影响另外一个问题的解）。

简单来讲目前遇到的困境就是：求解一个子问题时用到了某些资源（本例中是顶点），导致这些资源在求解其它子问题时不可用。

##### 3.2.重叠子问题

适合使用动态规划方法求解的最优化问题应该具备的第二个性质是子问题空间必须足够“小”，即问题的递归算法会反复的求解相同的子问题，而非一直生成新的子问题。如果递归算法反复求解相同的子问题，我们称最优化问题具有**重叠子问题**性质。

在上面过程中，分析过钢条切割的朴素递归方案性能为何会快速恶化的问题，其中可以看到原因是在底层的问题上进行反复求解。对于矩阵链乘法问题，也可以从实现的代码中看到，实在看不出来就加个打印看看。。。。。。。。

##### 3.3.重构最优解

具体问题具体分析，通常是将每个子问题所做的选择保存在一个表中，这样可不必根据代价值来重构这些信息。



#### 4.最长公共子序列

问题描述：给定两个序列 $$X=\langle x_1，x_2，\cdots ，x_m \rangle $$ 和  $$Y=\langle y_1，y_2，\cdots ，y_n \rangle $$ ，求 $$X$$ 和 $$Y$$ 长度最长的公共子序列。

**步骤1：刻画最长公共子序列的特征**

如果使用暴力搜索方法求解 LCS 问题，需要穷举 $$X$$ 所有的子序列（有 $$2^m$$ 个），对每个子序列检查它是否是 $$Y$$ 的子序列，记录找到的最长的子序列。容易得出，暴力方法运行时间是指数阶的，对较长的序列是不实用。

先给出一个严谨的前缀的定义：给定一个序列 $$X=\langle x_1，x_2，\cdots ，x_m \rangle $$，对 $$i = 0，1，\cdots，m$$ ，定义 $$X$$ 的第 $$i$$ 前缀为 $$X_i =\langle x_1，x_2，\cdots ，x_i \rangle $$。 

定理（LCS 的最优子结构）： 令 $$X=\langle x_1，x_2，\cdots ，x_m \rangle $$ 和  $$Y=\langle y_1，y_2，\cdots ，y_n \rangle $$ 为两个序列， $$Z=\langle z_1，z_2，\cdots ，z_k \rangle $$ 为 $$X$$ 和 $$Y$$ 的任意 LCS。

1. 如果 $$x_m = y_n$$ ， 则 $$z_k = x_m = y_n $$ 且 $$Z_{k-1} $$ 是 $$X_{m-1}$$ 和 $$Y_{n-1} $$ 的一个LCS。
2. 如果 $$x_m \neq y_n$$ ， 那么 $$z_k \neq x_m $$ 意味着 $$Z$$ 是 $$ X_{m-1} $$ 和 $$Y$$ 的一个LCS。
3. 如果 $$x_m \neq y_n$$ ， 那么 $$z_k \neq y_n $$ 意味着 $$Z$$ 是 $$ X $$ 和 $$Y_{n-1}$$ 的一个LCS。

证明： 比较容易理解，略。

**步骤2：一个递归解**

根据上一步给出的定理，我们在求解两个序列 $$X$$ 和 $$Y$$ 的一个LCS时，我们需要求解一个或者两个子问题。如果 $$x_m = y_n$$ ，我们只需要求解 $$X_{m-1} $$ 和 $$Y_{n-1}$$ 的一个LCS 并且将 $$x_m$$ 追加到这个LCS后面即可。如果 $$x_m \neq y_n$$ ，那么我们需要求解两个子问题：求 $$X_{m-1} $$ 和 $$ Y $$ 的一个LCS 以及 $$X$$ 和 $$Y_{n-1}$$ 的一个LCS 。两个LCS中较长者即为 $$X$$ 和 $$Y$$ 的一个LCS。

给出定义 $$c[i, j] $$ 表示 $$ X_i $$ 和 $$Y_j$$ 的 LCS 长度，如果 $$i=0$$ 或 $$j=0$$，那么其LCS长度为0，可得：
$$
c[i, j] = \left\{\begin{array}{ll}
0 & 若 \; i = 0 \; 或 \; j = 0 \\
c[i-1, j-1] + 1 & 若 \; i,j > 0 且 x_i = y_i \\
\max(c[i, j-1], c[i-1, j]) & 若 \; i,j > 0 且 x_i \neq y_i 
\end{array} \right.
$$
通过条件的形式限定，在某些情况下只需要求解一个子问题，而某些情况下需要求解两个子问题。

**步骤3：计算 LCS 的长度**

介于上一步的分析，我们很容易给出一个指数级时间的递归算法来计算两个序列的LCS长度。但由于 LCS 问题其实只有 $$\Theta(mn)$$ 个子问题，可以用动态规划的方法自底向上的进行计算。

```c++
int lcs_length(const string& A, const string& B) {
    int m = A.size(), n = B.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    vector<vector<char>> bk(m + 1, vector<char>(n + 1, 0));
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (A[i - 1] == B[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
                bk[i][j] = 'a'; // 表示来源于左上角数据
            } else  if (dp[i - 1][j] > dp[i][j - 1]) {
                dp[i][j] = dp[i - 1][j];
                bk[i][j] = 'u'; // up 表示来源于 dp[i - 1][j]
            } else {
                dp[i][j] = dp[i][j - 1];
                bk[i][j] = 'l'; // left 表示来源于 dp[i][j - 1]
            }
        }
    }
    // 通过保存的 bk 回溯出计算的路径
    return dp[m][n];
}
```



**步骤4：构造 LCS**

利用上面计算过程中保存的表 `bk` 快速构造 $$X$$ 和 $$Y$$ 的 LCS，只需要简单的从 `b[m, n]` 开始，根据字符指示追踪下去即可。

```c++
void print_lcs(const vector<vector<char>> &bk, const string& X, int i, int j) {
    if (i == 0 || j == 0) return;
    if (bk[i, j] == 'a') {
        print_lcs(bk, X, i - 1, j - 1);
        cout << X[i] << " ";
    } else if (bk[i, j] == 'u') {
        print_lcs(b, X, i - 1, j);
    } else {
        print_lcs(b, X, i, j - 1);
    }
    return;
}
```



**算法改进**

对上面执行的算法，可以完全去除表bk，因为给定 `c[i, j]`，的值，很容易在 $$O(1)$$ 的时间内判断出该值依赖于 `c[i-1, j]，c[i, j-1]，c[i-1, j-1]` 中的哪一项。当然，如果只需要知道 LCS 的长度值，我们大概还可以继续压缩只需要一行的空间多点就可以完成计算，但这个空间存储的信息不足以在 $$O(m+n)$$ 时间内完成重构工作。

#### 5.最优二叉搜索树

问题描述：给定一个 $$n$$ 个不同关键字的已排序序列 $$K = \langle k_1，k_2，\cdots ，k_n \rangle$$ （因此 $$k_1 < k_2 < \cdots < k_n $$），我们希望用这些关键字构造一棵二叉搜索树。对每个关键字 $$k_i$$ 都有一个与之对应的概率 $$p_i$$ 表示其搜索频率。有些需要搜索的值不在 $$K$$ 中，因此我们有 $$n+1$$ 个伪关键字 $$d_0，d_1，\cdots，d_{n} $$ 表示表示不在 $$K$$ 中的值。$$d_0$$ 表示所有小于 $$k_1$$ 的值，$$d_n$$ 表示所有大于 $$k_n$$ 的值，而 $$d_i$$ 表示所有介于 $$k_i$$ 与 $$k_{i+1} $$ 之间的值。对每个伪关键字都有一个对应的概率 $$q_i$$ 表示其搜索频率。因此，在构造出来的二叉树中，每个 $$k_i$$ 是一个内部结点，而每个 $$d_i$$ 则是叶节点。每次搜索，要么成功要么失败，所以有如下公式：
$$
\sum_{i=1}^{n}{p_i} + \sum_{i=0}^{n}{q_i} = 1
$$
因为我们知道每一个关键字和伪关键字的搜索概率，因而可以确定在一棵给定的二叉搜索树 $$T$$ 中进行一次搜索的期望代价。假定一次搜索的代价等于访问的结点数，即此次搜索找到的结点在 $$T$$ 中的深度加 1。那么在$$T$$ 中进行一次搜索的期望代价为：
$$
\begin{array}{lll}
E[T中搜索代价] & = & \sum\limits_{i=1}^{n}{(depth_T(k_i) + 1) * p_i} \; + \;
\sum\limits_{i=0}^{n}{(depth_T(d_i) + 1) * q_i} \\
& = & 1 + \sum\limits_{i=1}^{n}{depth_T(k_i) * p_i}  \; + \; \sum\limits_{i=0}^{n}{depth_T(d_i) * q_i}
\end{array}
$$
其中 $$depth_T$$ 表示一个结点在树 $$T$$ 中的深度。对于一个给定的概率集合，我们希望构造一棵期望搜索代价最小的二叉搜索树，称之为最优二叉搜索树。与上面的矩阵链乘法相似，穷举所有的可能性并不是一个最优算法，对于任意一棵 $$n$$ 个结点的二叉树，我们都可以通过对结点标记关键字 $$k_1，k_2，\cdots，k_n$$ 构造出一棵二叉搜索树，然后向其中添加伪关键字作为叶节点。



**步骤1：最优二叉搜索树的结构**

观察其子树特征开始，考虑一棵二叉树的任意一棵子树，它必须是包含连续关键字 $$k_i，\cdots ，k_j$$ ，$$ 1 \leqslant i \leqslant j \leqslant n $$ ，而且其叶节点必须是伪关键字 $$d_{i-1}，\cdots ，d_j $$ 。由此，可以给出一个二叉树的最优子结构：如果一棵最优二叉搜索树 $$T$$ 有一棵包含关键字 $$k_i，\cdots，k_j$$ 的子树 $$T'$$ ，那么 $$T'$$ 必然包含了关键字 $$k_i，\cdots ，k_j $$ 和伪关键字 $$d_{i-1}，\cdots ，d_j $$ 的子问题的最优解，同样可以通过反证法证明。

下一步我们需要用最优子结构的性质来证明，我们可以用子问题的最优解构造原问题的最优解。给定关键字序列 $$k_i，\cdots ，k_j$$ ，其中某个关键字 $$k_r(i \leqslant r \leqslant j)$$ 是这些关键字的最优子树的根结点。那么 $$k_r$$ 的左子树就包含关键字 $$k_i，\cdots ，k_{r-1}$$ ，右子树包含了 $$k_{r+1}，\cdots ，k_j$$ 关键字序列（也包括对应的伪关键字），此处需要注意的是根节点在序列边界情况下的处理，即关键字一定是内部结点，必定会包含伪关键字作为叶子结点的。

**步骤2：一个递归算法**

根据上一步，我们确定了一个子问题域：求解包含关键字 $$k_i，\cdots ，k_j$$ 的最优二叉搜索树，其中 $$i \geqslant 1 ，j \leqslant n \;且\; j \geqslant i - 1$$ 。定义 `e[i, j]` 表示包含关键字$$k_i，\cdots ，k_j$$ 的最优二叉搜索树中进行一次搜索的期望代价。最终，我们期望计算出 `e[1, n]` 。

对于 $$j =  i - 1$$ 的情况比较简单，其仅包含一个伪关键字 $$d_{i-1} $$ ，因此期望代价为 $$ e[i,\;i - 1] = q_{i-1} $$ 。

当 $$j \geqslant i $$ 时，我们需要从 $$k_i，\cdots ，k_j$$ 中选出一个根结点 $$k_r$$ ，分别构造其左右子树。当一棵子树成为一个结点的子树时，因其所有结点的深度都增加了1，其期望搜索代价的增加值应该为所有概率之和。对于包含关键字 $$k_i，\cdots ，k_j$$ 的子树，所有概率之和为：
$$
w(i, j) = \sum_{l=i}^{j}{p_l} + \sum_{l = i - 1}^{j}{q_l}
$$
因此，如果 $$k_r$$ 为包含关键字 $$k_i，\cdots ，k_j$$ 的最优二叉搜索树的根节点，我们有如下公式：
$$
e[i, j] = p_r + (e[i, r-1] + w(i, r-1)) + (e[r+1, j] + w(r+1, j))
$$
CAREFULLY:
$$
w(i, j) = w(i, r-1) + p_r + w(r+1, j)
$$
为何需要计算 $$w[i, j] $$ ？因为当子树整体高度加1时，$$w[i, j] $$ 是刚好需要增加的代价和，SO：
$$
e[i, j] = 
\left\{ \begin{array}{ll}
q_{i -1} & 若 j = i - 1 \\
\min\limits_{i\leqslant r \leqslant j}{e[i, r-1] + e[r+1, j] + w(i, j)} & 若 i \leqslant j
\end{array} \right.
$$
$$e[i, j] $$ 给出了最优二叉搜索树的期望搜索代价。为了记录最优二叉搜索树的结构，对包含关键字 $$k_i，\cdots ，k_j(1 \leqslant i \leqslant j \leqslant n)$$ 的最优二叉搜索树，可以定义 $$root[i, j] $$ 保存根节点 $$k_r$$ 的下标 $$r$$ 。

**步骤3：计算最优二叉搜索树的期望搜索代价**

给出代码实现：

```c++
vector<vector<float>> opt_bst(vector<float> p, vector<float> q, n) {
	vector<vector<float>> e(n + 2, vector<float>(n+1));
	vector<vector<float>> w(n + 2, vector<float>(n+1));
	vector<vector<int>> root(n + 1, vector<float>(n+1));
    for (int i = 0; i <= n + 1; ++i) {
        e[i, i-1] = q[i - 1];
        w[i, i-1] = q[i - 1];
    }
    for (int l = 1; l <= n; ++l) {
        for (int i = 1; i < n - l; ++i) {
            int j = i + l - 1;
            e[i, j] = MAX_FLOAT;
            w[i, j] = w[i, j-1] + p[j] + q[j];
            for (int r = i; r <= j; ++r) {
                float t = e[i, r-1] + e[r+1, j] + w[i, j];
                if (t < e[i, j]) {
                    e[i, j] = t;
                    root[i, j] = r;
                }
            }
        }
    }
    // 此时拿到的e 和 root是我们所需要的结果
    return e;
}
```

同矩阵链乘法问题一样，其时间复杂度也是 $$\Theta(n^3) $$ 。



#### 6.小结

动态规划方案实现，重点还是在抓住问题是否符合最优子结构和重叠子问题性质，如果想用该方法去解决问题，第一个问题需要面对的是子问题如何划分，此处如果划分不好压根儿没法整。在最后一个最优二叉搜索树问题中，刚开始考虑时如何划分的问题时，只想到给定的关键字序列中，选取一个作为根节点去划分子问题，后面看了下，貌似也还行？用根节点确定左右子树，，另外就是重叠子问题性质。
