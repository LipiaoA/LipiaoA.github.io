#### 算法导论-05-堆排序

##### 1.堆

堆是一个数组，其可以被看作一个完全二叉树按照层序存放的一维数组，下标 $i$ 从1开始的情况下，我们可以得到二叉树第 $i$ 个节点的左子节点下标为 $2i$，右子节点下标为 $2i+1$。

另外再区分另一个概念，大顶堆/小顶堆，大顶堆的性质是其节点 $i$ 的值都需要大于等于其子节点，小顶堆则刚好相反，因此根节点则是堆中的最大值或者最小值。

##### 2.排序

堆排序分n个步骤：

1. 建堆
2. 交换
3. 维护堆性质

```c
// 交换两个元素
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// 堆调整：保证以 root 为根的子树满足最大堆性质
void heapify(int arr[], int n, int root) {
    int largest = root;          // 当前根节点
    int left = 2 * root + 1;     // 左子节点
    int right = 2 * root + 2;    // 右子节点

    // 找出 root、left、right 中最大的一个
    if (left < n && arr[left] > arr[largest])
        largest = left;

    if (right < n && arr[right] > arr[largest])
        largest = right;

    // 若最大值不是根节点，则交换并递归调整
    if (largest != root) {
        swap(&arr[root], &arr[largest]);
        heapify(arr, n, largest);
    }
}

// 堆排序
void heapSort(int arr[], int n) {
    // 1. 建堆（从最后一个非叶子节点开始）
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);

    // 2. 依次取出堆顶（最大值），放到末尾
    for (int i = n - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);  // 把最大元素移到末尾
        heapify(arr, i, 0);      // 调整剩余部分为最大堆
    }
}

```

注：建堆的过程是通过调用堆调整实现的，上述 $n / 2 - 1$ 计算最后一个非叶子节点，从此处开始往上进行调整，后面的实现步骤则是依次把数组最后一个元素和堆顶进行交换，将堆元素减1，再进行堆调整，直到堆元素数量为1为止，排序结束。

时间复杂度分析，对上面的堆调整过程，简单的看下对每个元素进行调整的时间复杂度是 $\lg n$，总共进行调整次数为 $n$，因此得到最终时间复杂度是 $O(n\lg n)$, 但实际上该界限并不渐近紧确，问题在于对不同的节点进行调整时运行时间和其高度相关，大部分节点的高度都很小，可以通过以下方式进行计算，得到一个渐进紧确界：对一个包含 $n$ 个元素的堆，其高度为 $\lfloor \lg{n} \rfloor$; 高度为 $h$ 的堆，最多包含 $\lceil n/2^{h+1} \rceil$ 个节点，在一个高度为h的节点上进行堆调整代价为 $O(h)$，因此建堆的总代价可以表示为：
$$
\sum_{h=0}^{\lg{n}}{n/2^{h+1}}O(n) =
O(n\sum_{h=0}^{\lfloor \lg{n} \rfloor} {\frac{h}{2^h}})
$$
根据以下公式：
$$
\sum_{k=0}^{\infty}{kx^k} = \frac{x}{(1-x)^2}
$$
可以得到最终的时间复杂度为 $O(n)$，因此我们可以在线性的时间复杂度范围内建立一个大顶堆。后面的堆排序过程时间复杂度是 $O(n\lg n)$，总体时间复杂度为$O(n\lg n)$。



##### 3.应用

在排序中快速排序的性能一般会优于堆排序，此处提一个堆排序应用 -- 优先队列

优先队列是一种用来维护一组元素构成的集合S的数据结构，每个元素有一个key，一个最大优先队列支持以下操作：

1. 插入一个元素
2. 返回集合中最大key的元素
3. 去掉并返回S中具有最大关键字的元素
4. 增加某个关键字的key值

第一个操作插入一个元素，插入在数组最后，从下向上调整到合适的位置即可，返回最大key和去掉最大key元素也比较简单，对于增加某个key的值，同上面插入类似，先增加key的值，从当前节点开始向上查找合适的位置。
