##### 算法导论-06-快速排序

##### 1.排序过程

快速排序使用分治思想，分治的三步骤分别做下面的事儿：

1. 分解：将数组 $A[p...r]$ 划分为 $A[p...q-1]，A[q+1...r]$ 两个数组，使得数组 $A[p...q-1]$ 中的每个元素都小于 $A[q]$，数组 $A[q+1...r]$ 中的每个元素都大于等于 $A[q]$。
2. 解决：递归调用快速排序，对数组 $A[p...q-1]$ 和 $A[q+1...r]$ 进行排序。
3. 合并：数组原地址进行排序，不需要合并操作。



```c
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i + 1], &arr[high]);
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    if (low >= high) return;
    int pi = partition(arr, low, high);
    quickSort(arr, low, pi - 1);
    quickSort(arr, pi + 1, high);
}
```

##### 2.性能分析



**最坏情况**

划分为 $n - 1$ 个元素和 0 个元素的两个子问题，假定每次递归情况都出现了该种划分，划分操作时间复杂度为 $\Theta(n)$，对长度为0的数组划分函数直接返回，因此 $T(0) = \Theta(1)$，算法运行递归式可以表示为：
$$
T(n) = T(n - 1) + T(0) + \Theta(n) = T(n-1) + \Theta(n)
$$
结果为 $\Theta(n^2)$，因此在最坏情况下，快速排序的执行时间并不比插入排序要好，在同等情况下插入排序的执行时间为 $O(n)$。通用一点儿再仔细分析一把，$T(n)$ 为最坏情况下快排在输入规模为 $n$ 上面所花费时间，则有：
$$
T(n) = max{(T(q) + T(n - q - 1))} + \Theta(n)
$$
因为划分函数生成的两个子问题规模为 $n - 1$，因此 $0 \leqslant q \leqslant n-1$，我们不妨猜测 $T(n) \leqslant cn^2$ 成立，其中 $c$ 为常数，代入上面的式子可以得到：
$$
\begin{array}{ll} \\
T(n) & \leqslant max(cq^2 + c(n - q - 1)^2) + \Theta(n) \\
& = c \; \cdot \; max(q^2 + (n - q - 1)^2) + \Theta(n)
\end{array}
$$
上述表达式在 $q$ 的端点处取到最大值，可以得到 $max(q^2 + (n - q - 1)^2) \leqslant (n - 1)^2 = n^2 - 2n + 1$ 代入上面可以得到 $T(n) \leqslant cn^2$，同样上面的 $T(n)$ 的递归式也能得到另一个解 $T(n) = \Omega(n^2)$，因此我们可以得到快速排序在最坏情况下的时间为 $\Theta(n^2)$ 。

**最好情况**

该情况下，每次对问题划分的规模都不超过 $n / 2$，此情况下快速排序性能最优，算法执行时间递归式为：
$$
T(n) = 2T(n/2) + \Theta(n)
$$
最终时间为 $T(n) = \Theta(n\lg{n})$，通过在每一层中做出平衡的划分，我们可以达到到快速排序的最优情况，但在实际的运用中，平均情况一般可以达到最优，可以到到 $O(n\lg n)$ 的时间复杂度。



**期望运行时间**

快速排序算法执行时间是划分函数花费的时间所决定的，每次对该划分函数的调用都会挑选一个元素，而该元素不会出现在后续的快速排序和划分操作调用中，对该函数的调用次数不会超过 $n$ 次该函数中，其核心操作为比较操作，我们选取该操作作为衡量时间代价，定义 $X$ 为所有调用比较总次数，将数组A元素重命名为 ${z_1, z_2, ... z_n}$，定义 $Z_{ij} = \; \{z_i,\; ...\; z_j\;\}$ 为 $z_i \;与\; z_j$ 之间(包含边界)的元素集合，定义事件 $X_{ij} = \{\; z_i \;与\; z_j \;进行比较\}$ ，因此我们可以得到总的比较次数如下：
$$
X = \sum_{i=1}^{n-1}\sum_{j = i+1}^{n}X_{ij}
$$
对两边取期望，可以得到：
$$
E(X) = \sum_{i=1}^{n-1}\sum_{j = i+1}^{n}E(X_{ij}) =  \sum_{i=1}^{n-1}\sum_{j = i+1}^{n}{Pr\{\;z_i\;与\;z_j\;进行比较\;\}}
$$
对于 ${Pr\{\;z_i\;与\;z_j\;进行比较\;\}}$ 进一步计算，直观的，$z_i$ 与 $z_j$ 需要进行比较，那么需得其中一个元素被选中作为主元素，因此其概率为：
$$
Pr\{\;z_i\;与\;z_j\;进行比较\;\} = \frac{2}{j-i+1}
$$
进一步可以得到：
$$
E[X] = \sum_{i=1}^{n-1}\sum_{j = i+1}^{n}{\frac{2}{j-i+1}}
$$
做个简单代换 $(k = j - i)$ ,可以得到：
$$
E[X] = \sum_{i=1}^{n-1}\sum_{j = i+1}^{n}{\frac{2}{j-i+1}} =
\sum_{i=1}^{n-1}\sum_{k= 1}^{n-i}{\frac{2}{k+1}} <
\sum_{i=1}^{n-1}\sum_{k= 1}^{n-i}{\frac{2}{k}} =
\sum_{i=1}^{n-1}{O(\lg{n})} = O(n\lg{n})
$$
于是我们可以得出结论，快速排序排序算法期望运行时间是 $O(n\lg{n})$，注意一个计算中的点，算概率时的方式要求我们在选取比较的值(主元)时需要随机选取，否则概率不成立。
